# AuthService

AuthService is a modular microservice built with Spring Boot that handles user authentication, registration, and JWT-based authorization. It provides secure REST APIs with role-based access control to protect downstream services in scalable applications.

## Features

- User registration and login
- JWT token generation and validation
- Role-based access control (RBAC)
- Secure REST API endpoints
- Integration with PostgreSQL for user data storage

## Tech Stack

- Java 17+
- Spring Boot
- Spring Security
- JWT (JSON Web Tokens)
- PostgreSQL
- Maven
